Privacy Policy - Friday

Last updated: 2026-11-09

Who uses this app

Friday is a private assistant program used only by its owner (kimdd9001@gmail.com). It has no other users.

What Google data it accesses

  • Gmail (gmail.modify): read request mails, send replies, and add labels. It never deletes mail permanently.
  • Google Calendar (calendar): read and add the owner's events.
  • Google Drive (drive.file): only files that Friday itself creates or that the owner opens with it.
  • Basic account info (email address): to confirm the correct account is signed in.

How the data is used and stored

The data is used only to carry out the owner's own requests. It is processed and stored on the owner's own computer. It is not sold, not used for advertising, and not shared with anyone else.

Friday's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can remove Friday's access at any time at myaccount.google.com/permissions. Local copies can be deleted from the owner's computer.
